# 基本型

コピーが安く、これ以上分解できない型。

| 型 | 中身 | 既定値 |
|---|---|---|
| `int` | 64ビット符号付き整数 | `0` |
| `float` | 64ビット浮動小数点数（IEEE 754） | `0.0` |
| `bool` | `true` / `false` | `false` |
| `void` | 値がないことを表す。戻り値の型にだけ書ける | — |

`int` を 64 ビット固定にするのは、プラットフォームによって結果が変わらないようにするため。
32ビットしかない環境でも 64 ビットとして振る舞わせる。

## 数値の規則

- 整数の除算 `/` は整数を返し、0 方向に切り捨てる（`-7 / 2` は `-3`）
- 剰余 `%` の符号は**割られる数**に従う。C 言語と同じ
  - `-7 % 2` は `-1`、`7 % -2` は `1`
  - `a == (a / b) * b + a % b` が常に成り立つ
- 0 除算は実行時エラー（[../runtime/error.md](../runtime/error.md)）
- `int` と `float` を混ぜた計算は**書けない**。どちらかに明示変換する

```shark
var a = 1;
var b = 2.0;
var c = a + b;          // エラー: int と float は足せない
var d = float(a) + b;   // OK
```

暗黙変換を持たないのは「型を厳格に定める」という思想から。
どこで精度が落ちたかがコードを読めば分かる状態にする。

エラーは直し方（`float(a) + b`）まで示す（[../runtime/diagnostics.md](../runtime/diagnostics.md) E0102）。

## 真偽値の規則

`if` や `while` の条件に書けるのは `bool` だけ。
0 や空文字列を偽として扱うことはしない。

```shark
if n {}          // エラー
if n != 0 {}     // OK
```

## ビット演算

`int` には `&` `|` `^` `~` `<<` `>>` を書ける。動きは C と同じで、
ずらす幅だけは 0 〜 63 に決めてある（[../syntax.md](../syntax.md)）。

## オーバーフロー

`int` の計算があふれたときは実行時エラーにする。黙って一周させない。
あふれてもよい計算には、明示的に `wrapping_add` などのメソッドを用意する。
