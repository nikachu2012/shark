# 型推論

「型を厳格に定め、型推論を行う」を実現する規則。
推論は**関数の中だけ**で行い、関数の外から見える部分の型は必ず書く。

## 書かなくてよいもの

変数の型は、初期値から決まる。

```shark
var n = 10;             // int
var pi = 3.14;          // float
var name = "Shark";     // string
var xs = [1, 2, 3];     // list<int>
var m = {"a": 1};       // map<string, int>
var f = Fish("さめ");   // Fish
```

`for` の変数もコレクションから決まる。

```shark
for var x in xs { }     // xs が list<int> なら x は int
```

## 必ず書くもの

| 場所 | 理由 |
|---|---|
| 関数の引数と戻り値 | 呼ぶ側が定義を読まずに使えるようにするため |
| クラスのメンバ変数 | 同上 |
| 初期値のない変数 | 決めようがないため |
| 空のコレクションリテラル | 要素の型が決まらないため |

```shark
func add(a: int, b: int) -> int { }   // 省略できない
var x;                                // エラー
var x: int;                           // OK（既定値 0 で始まる）
```

## 推論の範囲

推論は宣言のその行だけで完結する。後の行の使われ方から遡って決めることはしない。

```shark
var xs = [];        // エラー。後で xs.push(1) があっても list<int> とは決めない
```

これは、実装を単純に保ち、どのプラットフォームでも同じ結果になるようにするため。
また、行を読んだだけで型が分かる状態を保つため。

エラーには `var xs: list<int> = [];` という書き足し方を示す（[../runtime/diagnostics.md](../runtime/diagnostics.md) E0104）。

## 型が変わらないこと

一度決まった変数の型は、後から変わらない。

```shark
var n = 10;
n = "abc";     // エラー
```

## リテラルの既定の型

- 小数点も指数もない数値リテラルは `int`
- 小数点か指数がある数値リテラルは `float`
- 文脈によって型が変わることはない（`var f: float = 1;` はエラー、`1.0` と書く）
