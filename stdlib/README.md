# stdlib/ — 標準ライブラリ宣言ファイル

標準ライブラリの **名前・型定義・ドキュメント・サンプルコード** は、本ディレクトリの `.shk` ファイルが正（マスター）です。
C++ 実装（`core/lib/*.cpp`）は実行ロジックのみを保持し、ドキュメントコメントは含みません。

| ファイル | 概要 |
|---|---|
| [`builtin.shk`](builtin.shk) | `import` なしでグローバルに利用可能な組込関数群 |
| [`types.shk`](types.shk) | `string` `list` `map` `Result` 等、コア組込型とそのメソッド群 |
| `math.shk` `time.shk` … | `import std.xxx;` で読み込む標準モジュール群（1ファイル1モジュール） |
| [`prelude.shk`](prelude.shk) | **宣言ではなく Shark 実装コード**。Shark 自身で記述されたソート等の標準処理 |
| [`prelude_ui.shk`](prelude_ui.shk) | 同じく実装コード。宣言的 UI のエントリポイント（`ui.run` 等） |

宣言ファイルを解析するのは [`tools/shkdoc.py`](../tools/shkdoc.py) です。以下の用途で使用されます。

```
make docs         docs/reference/ にモジュール別 HTML リファレンスを生成
make web          Web プレイグラウンドの入力補完定義（api.js）を生成
make docs-check   宣言ファイル内のサンプルコードをすべて shark で実行検証
```

## 記述フォーマット

```shark
/// std.math                      ← module 文の直前はモジュールの概要説明
///
/// 数学計算および乱数生成。
module std.math;

/// 平方根を計算します。負の数の場合は NaN を返します。 ← 1行目が概要一覧に表示される。空行で段落区切り
///
/// 引数:
///   x   0 以上の浮動小数点数
///
/// 例:
///   print(math.sqrt(9.0));   // 3.0
func sqrt(x: float) -> float;
```

- 関数宣言は **本体を持たず**、`func 名前(引数) -> 戻り値;` の形式でセミコロンで終えます
- 型に属するメソッドは `class` ブロックで囲みます: `class list<T> { func push(v: T) -> void; }`
- 定数定義は `const PI: float;` のように記述します
- 同一関数名を多重定義（オーバーロード）する場合、ドキュメントコメントは最初の定義に記述します
- セクション見出しとして認識されるのは `引数:` `戻り値:` `例:` `注意:` の4種です。インデントされた行がそのセクションの内容となります

## サンプルコードの規約

**すべての関数に動作するサンプルコードを記述します。** `make docs-check` により全サンプルが実際に `shark` で実行されるため、動作しないコードは含められません。

- サンプルコードは **単独で完結** させます。入力データやレシーバーもサンプルコード内で初期化してください
- 当該モジュールの `import` 文は自動補完されるため記述不要です（他モジュールを併用する場合のみサンプル内で明示 `import` します）
- 実行結果の期待値は `// 3` のように行末コメントとして記述します。
  `python3 tools/runex.py --show <名前の一部>` で、実際の実行出力と比較検証できます
- 外部プロセスの起動やネットワーク通信など、CI 環境で自動実行できないサンプルは `例（動かさない）:` と記述します

## C++ 実装との突合検証

`make docs` 実行時、宣言ファイルと C++ 側の登録情報（`core/lib/*.cpp` の `r.add` および `core/check.cpp` の型検査メソッドテーブル）を突合します。
**片方にしか存在しないシンボルがある場合はエラーとして報告されます。**
標準ライブラリに関数を追加した場合は、必ず本ディレクトリの宣言ファイルにも定義を追加してください。
