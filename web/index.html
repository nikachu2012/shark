つかいかた

左に書いて 実行。処理系そのもの（C++ で書いたコア）を WebAssembly にしたものが、 このタブの中だけで動きます。書いたものはどこにも送られません。

手数

  • 実行 … main（または並べた文）を動かす
  • 型検査 … 動かさずに、誤りだけを見る
  • テスト … test_ で始まる関数を順に走らせる
  • 止める … 途中でやめる。止まらない繰り返しでも画面は固まりません

ターミナル

右がわは端末とおなじ流れです。出力も、打った文字も1本に並び、 出る形は shark コマンドと同じにしてあります。

  • input() は打たれるまで待ちます。そのまま打って Enter
  • ボタンを押さずに、run check test explain E0102 modules と打っても動きます（help で一覧）
  • Ctrl + C … 止める　/　Ctrl + D … 入力の終わり（none になる）
  • Ctrl + L … 流れを消す　/　↑ ↓ … 打った覚え

覚えておくと早い

  • Ctrl（⌘）+ Enter … 実行
  • Ctrl（⌘）+ . … 止める
  • Ctrl（⌘）+ Space … 入力候補を出す
  • F12 … 定義へ飛ぶ　/　Ctrl + Shift + O … 関数を探す
  • F1 … 書くところでできることを並べる

入力補完

  • 標準ライブラリの候補と説明は、この処理系が実際に持っている関数から作ってあります
  • math. のように打つと、そのモジュールの関数が出ます。 import がまだ無ければ一緒に書き足します
  • 変数の後ろの . では、見当をつけた型のメソッドが出ます
  • 赤い波線は本物の型検査の結果です（打つ手を止めると走ります）

画面（std.ui）

ui.open() を呼ぶと画面のタブが出て、そこに面が出ます。 キーもマウス（指も）もそのまま届きます。

  • 面の大きさは ui.open(横, 縦) のまま。板の境目を引くと、面もその大きさに作り直されます （ui.open(..., false) なら変わりません）
  • ui.field の日本語は、ブラウザのかな漢字変換がそのまま使えます
  • 閉じるを押すと ui.poll() が false を返します（窓の × と同じ）
  • 字は内蔵の 5×7（ASCII）だけです。ui.font() は false を返します

ブラウザでできないこと

  • std.file が触るのは、このタブの中だけにある仮の置き場です。閉じると消えます
  • os.run()（外のプログラムを呼ぶ）は使えません
  • 読めるファイルは playground.shk（左に書いているもの）だけです
