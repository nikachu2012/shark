つかいかた

左に書いて 実行。処理系そのもの（C++ で書いたコア）を WebAssembly にしたものが、 このタブの中だけで動きます。書いたものはどこにも送られません。

機能

  • 実行 … main（またはトップレベルスクリプト）を実行
  • 型検査 … 実行せずに静的型検査のみを実行
  • テスト … test_ で始まるユニットテスト関数を順次実行
  • フォーマット … コードを自動整形（shark fmt 相当）。 Shift + Alt + F でも実行可能
  • 停止 … スクリプトの実行を強制停止。無限ループ時もブラウザがフリーズしません
  • ドキュメント … 標準ライブラリ一覧と言語仕様をウィンドウで表示 （Ctrl（⌘）+ I）。エディタと並行して閲覧・操作できます

ターミナル

右ペインは CLI ターミナルと同様に対話形式で動作し、標準出力・標準エラー出力・入力が統合表示されます。

  • input() は標準入力を待機します。文字を入力して Enter を押してください
  • ボタンを押さずに、ターミナルで run check test fmt explain E0102 modules と入力してコマンド実行することも可能です（help でコマンド一覧）
  • Ctrl + C … 実行停止　/　Ctrl + D … EOF（入力終了）
  • Ctrl + L … 画面クリア　/　↑ ↓ … コマンド履歴

ショートカットキー

  • Ctrl（⌘）+ Enter … 実行
  • Ctrl（⌘）+ . … 停止
  • Ctrl（⌘）+ Space … コード補完の表示
  • F12 … 定義へジャンプ　/　Ctrl + Shift + O … シンボル検索
  • Ctrl（⌘）+ I … ドキュメントウィンドウの表示切り替え
  • F1 … コマンドパレットを開く

入力補完

  • 標準ライブラリの候補と説明は、この処理系が実際に持っている関数から作ってあります
  • math. のように打つと、そのモジュールの関数が出ます。 import がまだ無ければ一緒に書き足します
  • 変数の後ろの . では、見当をつけた型のメソッドが出ます
  • 赤い波線は本物の型検査の結果です（打つ手を止めると走ります）

GUI（std.ui）

ui.open() を呼び出すと仮想ウィンドウが表示され、キーボードやマウス（タッチ）イベントが送信されます。

  • タイトルバーをドラッグしてウィンドウを移動できます。右下隅をドラッグするとサイズを変更でき、描画サーフェスも自動的にリサイズされます （ui.open(..., false) の場合は固定サイズとなります）
  • × ボタンをクリックすると ui.poll() が false を返します（デスクトップウィンドウと同様）
  • ui.field のテキスト入力では、ブラウザのネイティブ IME によるかな漢字変換がそのまま利用可能です
  • テキスト描画はブラウザの Canvas API を使用します。ui.font(12 * ui.scale()) により システムフォントを用いた日本語表示に対応し、適用中のフォントは ui.font_name() で取得できます

ブラウザ環境の制限事項

  • std.file がアクセスするのはブラウザ内仮想ファイルシステム（メモリ上）です。タブを閉じるとデータは破棄されます
  • os.run()（外部プロセスの実行）は Web 環境では使用できません
  • 初期状態で読み込めるファイルは playground.shk（エディタ上のコード）のみです
