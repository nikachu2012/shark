# Shark 入門・実践ガイド（やさしい解説書）

**〜ゲームを作りながら楽しく学ぶ、Shark プログラミング〜**

Shark（シャーク）は、ゲーム機やパソコンで動く「プログラミング学習用ゲーム」のために開発されたプログラミング言語です。

「プログラミングを初めて学ぶ人でも、迷わず安心して書けること」、そして「ゲームや便利なアプリをサクサク作れること」をとても大切にしています。

この解説書は、画面に文字を表示する最初の一歩から、ゲーム作りに欠かせない計算やループ、Shark の最大の特徴である「コピーの仕組み」、そして画面にボタンや図形を出す GUI（グラフィックス）やアプリ開発まで、章を追ってひとつひとつ分かりやすく解説していきます。

プログラミングが初めての方も、他の言語を少し触ったことがある方も、ぜひリラックスして読み進めてみてください！

## 第1章 Shark ってどんな言語？（設計思想と特徴）

### 1.1 ゲーム機で動く学習用言語

Shark（シャーク）は、Nintendo Switch などのゲーム機や教育用パソコンで動く「**プログラミング学習ゲーム**」の中で動くことを目指して生まれたプログラミング言語です。

「プログラムを書いてみたいけれど、エラーがたくさん出て難しそう……」
「ゲームを作ろうとしたら、知らないところでデータが書き換わってバグだらけになってしまった……」

Shark は、こうした初心者が最初につまずきやすい壁を取り除き、**誰でも安心して楽しくプログラミングを学べるように**作られています。

#### ゲーム機でもサクサク動く軽快さ
Shark の心臓部はとてもシンプルで、余計な外部ライブラリを一切必要としません。そのため、パソコンはもちろん、ゲーム機や Web ブラウザの上でも軽快に動作します。

#### 無限ループになってもフリーズしない安心感
プログラム初心者のころは、うっかり終わりがないループ（無限ループ）を書いてしまうことがよくあります。
ふつうの言語だとゲーム機やパソコンごと固まってしまうことがありますが、Shark は「一定回数動いたら一度ゲーム本体に制御を戻す」という仕組みが組み込まれているため、ゲーム機がフリーズする心配がありません。失敗を恐れずに思い切ってコードを試せます。

---

### 1.2 一番大事なルール：「代入すると必ずコピーされる」

Shark を学ぶうえで、**いちばん大切な約束**があります。
それは、**「変数に入れたり、関数に渡したりしたデータは、ぜんぶコピーされる」** というルールです。

たとえば、ノートに書いたメモを友達に見せる場面を想像してください。
他のプログラミング言語（Python や JavaScript など）では、友達に「ノートそのもの」を渡してしまうため、友達がノートに落書きをすると自分の手元のノートまで汚れてしまいます。

```shark
var a = [1, 2, 3];
var b = a;          // a の中身を新しいノートに丸ごとコピーして b に渡す！
b.push(4);          // b に 4 を追加する

print(a.len());     // 3 のまま！（a のノートは絶対に汚れない！）
print(b.len());     // 4
```

Shark では、**コピー機でノートを丸ごとコピーして渡す**ような動きをします。
そのため、渡した先でどれだけデータを変更されても、元のデータは絶対に壊れません。

#### 「重くならないの？」という疑問へ
「毎回コピーしていたらメモリがたくさん必要で遅くなるのでは？」と思うかもしれません。
実は Shark は頭が良く、**「本当に中身を書き換える瞬間」まで実際のコピーを行いません**（コピーオンライトといいます）。見るだけなら一瞬で終わるため、速さと安全性を両立しています。

また、データがあちこちで複雑に絡み合わないため、ゲームのプレイ中に画面が一瞬カクつく原因になる重い「ごみ集め処理（ガベージコレクション）」も不要です。いつでもなめらかにゲームが動きます。

---

### 1.3 「知らないうちにバグる」を防ぐ工夫（null や例外がない）

プログラムを難しくする「3大トラブル」を、Shark は最初からなくしました。

| なくなったもの | なぜなくしたの？ | Shark での代わりの仕組み |
|---|---|---|
| **null（ヌル）** | 急に「値がない」と言われてゲームが止まる最大の原因だから | **オプショナル型（`T?`）**<br>「空っぽかもしれない箱」として最初から明示します |
| **例外（try-catch）** | エラーのときにコードがどこへ飛んでいくか分からなくなるから | **Result 型**<br>関数の戻り値として「成功したか失敗したか」を手渡しします |
| **async / await** | 非同期の処理が複雑になり、関数の書き方が分かれてしまうから | **タスク（`task`）**<br>ふつうに書いた関数をそのまま裏で走らせることができます |

すべてが「見た目どおり」に動くので、コードを追うのがとても簡単です。

---

### 1.4 すぐに遊べる・作れる標準機能（バッテリー内蔵）

Shark には、ゲームやアプリ作りに必要な道具が最初からすべてそろっています（これを「バッテリー内蔵 / Batteries included」と呼びます）。

インターネットから別のソフトを探してダウンロードしてくる必要はありません。
- **計算・算数**（`std.math`）: 三角関数や平方根、ランダムな計算
- **セーブデータの保存**（`std.file`, `std.path`, `std.json`）: ファイルの読み書き
- **タイマー**（`std.time`）: 時間をはかる・一定時間待つ
- **画面にお絵描き・ゲーム作り**（`std.ui`）: 四角や丸、文字の描画、キー操作
- **ボタンや文字のアプリ作り**（`std.ui`）: かんたんに作れるウィンドウ画面

Shark ひとつあれば、すぐに自分だけのゲームやツールを作り始めることができます！

## 第2章 最初の一歩：動かしてみよう

### 2.1 はじめてのプログラム（Hello, Shark!）

まずは定番の「画面にメッセージを出す」プログラムを動かしてみましょう！
メモ帳やテキストエディタで `hello.shk` というファイルを作り、次の 1 行を書きます。

```shark
// hello.shk
print("Hello, Shark!");
```

ターミナル（黒い画面）を開いて、次のコマンドを実行します。

```console
$ shark run hello.shk
Hello, Shark!
```

画面に `Hello, Shark!` と表示されたら大成功です！

---

### 2.2 手軽に動かすスクリプトと、ちゃんとした main 関数

Shark には、2 つの書き方があります。

#### 1. スクリプトモード（手軽な書き方）
先ほどの例のように、ファイルの上に直接やりたいことを並べる書き方です。短い計算やちょっとした実験をするときに便利です。

```shark
print("1 + 1 は");
print(1 + 1);
```

#### 2. main 関数を使った書き方（本格的な書き方）
ゲームや大きなプログラムを作るときは、スタート地点として `main` 関数を書きます。

```shark
func main() -> int {
  print("ゲームを開始します！");
  return 0; // 「問題なく終わりました（終了コード 0）」を返す
}
```

> [!NOTE]
> **どちらか一方を選びましょう**:
> `main` 関数を書いたファイルでは、関数の外に直接 `print(...)` などの実行文を置くことはできません。どちらの書き方にするか統一しましょう。

---

### 2.3 shark コマンドの基本的な使い方

Shark のコマンドはとてもシンプルです。

```console
$ shark run game.shk       # プログラムを動かす
$ shark check game.shk     # 動かさずに、間違い（文法や型のミス）がないか調べる
$ shark build game.shk     # 誰でも遊べる単独の実行ファイル（アプリ）にまとめる
$ shark fmt -w game.shk    # プログラムの見た目（字下げなど）をきれいに整える
$ shark test game.shk      # 作ったテストを一気に動かして確認する
$ shark explain E0102      # エラー番号の意味と直し方を教えてもらう
```

### 2.4 コメントと文末のセミコロン

#### コメント（自分用のメモ）
プログラムの中にメモを残しておけます。コメントは実行時には無視されます。

```shark
// ここから行末まではコメントです（1行メモ）

/* ここから
   ここまで全部コメントです（複数行メモ）
   /* コメントの中にコメントを入れる（入れ子）もできます */ */
```

#### 文の終わりにはセミコロン `;` をつける
Shark では、1 つの命令（文）が終わったら最後にセミコロン `;` をつけます。
ただし、波かっこ `{ ... }` で囲まれたブロックの終わりにはセミコロンは要りません。

```shark
var score = 0;       // 文の終わりなので ; が必要
print(score);        // これも文なので ; が必要

if score == 0 {
  print("ゼロ！");   // ブロックの中の文には ; が必要
}                    // 波かっこの終わりには ; は付けなくて OK
```

---

### 2.5 エラーが出たときの見方と直し方

最初はたくさんエラーが出るのが当たり前です。Shark は「あとでゲームが急に止まって悲しい思いをしないように、動かす前に教えてくれる先生」のような存在です。

エラーが出たときは、画面を落ち着いて読んでみましょう。

```text
error[E0102]: 型の不一致です
  --> main.shk:3:13
   |
 3 | var total = count + price;
   |             ----- int 型です
   |                     ----- float 型です
   = hint: float(count) + price と書くと計算できます
```

- **どこが間違っているか**（3行目のどこか）
- **なぜダメなのか**（整数と小数はそのまま足せない）
- **どう直せばいいか（hint）**（`float(...)` で合わせよう）

エラーコード（`E0102` など）が出たら、`shark explain E0102` とコマンドを打てば、さらに詳しい解説を読むこともできます。

## 第3章 データと計算（変数・型・演算子）

### 3.1 値を入れておく箱：変数（var）と定数（const）

プログラムでは、点数やプレイヤーの名前など、いろんなデータを保存しておきます。そのための「名前のついた箱」が**変数**と**定数**です。

```shark
// あとから中身を変えられる箱（var）
var hp = 100;
hp = 80; // ダメージを受けたので減らす（OK！）

// あとから絶対に中身を変えられない箱（const）
const MAX_PLAYERS = 4;
// MAX_PLAYERS = 5; // エラー！ 定数は書き換えられません
```

「ステージ番号」や「重力の強さ」など、ゲーム中に変わってほしくない値には `const` を使うと、うっかり書き換えてしまうミスを防げます。

---

### 3.2 データの種類（int, float, bool, string）

Shark には、基本となる 4 つのデータの種類（**型**）があります。

| 型の名前 | どんなデータ？ | 書き方の例 |
|---|---|---|
| `int`（整数） | 小数点のない数。コインの枚数や HP など | `0`, `42`, `-10` |
| `float`（小数） | 小数点のある数。プレイヤーの座標や移動スピードなど | `3.14`, `-0.5`, `1.0` |
| `bool`（真偽値） | 正しい（`true`）か間違い（`false`）か | `true`, `false` |
| `string`（文字列） | 文字のあつまり。名前やメッセージなど | `"こんにちは"`, `"Shark"` |

---

### 3.3 自動で型を決めてくれる型推論

変数を作るとき、毎回型を書かなくても、最初に入れた値から Shark が自動的に「この箱は整数だな」「文字列だな」と判断してくれます。

```shark
var level = 1;         // 自動的に int 型になる
var speed = 5.5;       // 自動的に float 型になる
var is_alive = true;   // 自動的に bool 型になる
var player = "勇者";   // 自動的に string 型になる
```

もちろん、わかりやすくするために自分で型を書いても構いません。
```shark
var score: int = 0;
```

---

### 3.4 型の変換（キャスト）

Shark は型にとても誠実です。「整数」と「小数」を混ぜて計算しようとすると、自動で適当に合わせることはせず、「ちゃんと教えてね」とエラーにします。

型を合わせたいときは、型名の関数を使って明示的に変換（キャスト）します。

```shark
var a = 10;
var b = 2.5;

// var sum = a + b; // エラー！ int と float はそのまま足せない
var sum = float(a) + b; // a を小数（10.0）に変えてから足すので 12.5（OK！）

var text = "得点: " + string(a); // 数値を文字に変える
```

#### 文字列を数値に変えるとき
文字から数字への変換は、「"123"」のようにうまくいく場合もあれば、「"abc"」のように数字に直せない場合もあります。
そのため、`int("123")` は「**もしかしたら失敗するかもしれない値（オプショナル型 `int?`）**」を返します。

`??` 演算子を使うと、「失敗したときはこの値にしてね」と指定できます。

```shark
var port = int("8080") ?? 80;   // 成功して 8080 になる
var fail = int("abc") ?? 0;     // 失敗したので 0 になる
```

---

### 3.5 算術計算・比べる・つなぐ演算子

#### 算数（算術演算子）
- `+` : 足し算
- `-` : 引き算
- `*` : 掛け算
- `/` : 割り算（整数同士の割り算は小数が切り捨てられます。`7 / 2` は `3`）
- `%` : 割った余り（`7 % 2` は `1`。偶数奇数の判定や、時計のような周回計算によく使います）

```shark
var hp = 100;
hp -= 20; // 20 減らす（hp = hp - 20 と同じ）
```

#### 比べる（比較演算子）
結果は必ず `true` か `false` になります。
- `==` : 等しい
- `!=` : 等しくない
- `<` / `>` : より小さい / より大きい
- `<=` / `>=` : 以下 / 以上

```shark
print(10 > 5);        // true
print("さめ" == "さめ"); // true
```

#### つなぐ（論理演算子）
- `&&` : かつ（AND。両方とも true なら true）
- `||` : または（OR。どちらか一方でも true なら true）
- `!`  : ではない（NOT。true と false をひっくり返す）

```shark
var can_enter = (level >= 10) && has_key;
```

---

### 3.6 変数の使える範囲（スコープ）

波かっこ `{ ... }` で囲まれた内側で作った変数は、そのかっこを出ると消えてなくなります。この変数が生きている範囲を**スコープ**と呼びます。

```shark
var outside = "外側";

if true {
  var inside = "内側";
  print(outside); // 外側の変数は見えるので OK！
  print(inside);  // 内側の変数なので OK！
}

// print(inside); // エラー！ かっこの外に出ると inside はもう存在しない
```

部屋の中で作ったものは部屋の外からは見えない、と覚えておきましょう。

---

## 第4章 動きをコントロールする（条件分岐とループ）

### 4.1 もしも〜なら：if 文による条件分岐

ゲームは「もし敵にぶつかったら」「もしコインを取ったら」といった条件の連続です。条件によって動きを変えるには `if` 文を使います。

```shark
var hp = 50;

if hp <= 0 {
  print("ゲームオーバー……");
} else if hp < 30 {
  print("ピンチ！ 体力が少ない！");
} else {
  print("まだまだ元気！");
}
```

条件式のまわりの丸かっこ `()` はあってもなくても構いませんが、ブロックの波かっこ `{ ... }` は 1 行だけでも必ず書くのが Shark のルールです。

---

### 4.2 条件式は必ず true か false にする

他の言語では「0 は偽」「1 は真」のように数値で条件判定できることがありますが、Shark では**必ず `bool` 型（true / false）になる式を書く**必要があります。

```shark
var count = 0;

// エラーになる書き方:
// if count { ... } // エラー！ 数値をそのまま条件にはできない

// 正しい書き方:
if count > 0 {
  print("まだアイテムがあるよ");
}
```

「うっかり間違えて 0 のチェックを忘れた」というミスが起きないための、やさしい親切設計です。

---

### 4.3 条件が続くあいだ繰り返す：while ループ

「敵をすべて倒すまで」「ゲームが終わるまで」のように、条件が満たされている間ずっと繰り返したいときは `while` ループを使います。

```shark
var count = 3;

while count > 0 {
  print(f"カウントダウン: {count}");
  count -= 1;
}

print("スタート！");
```

出力:
```text
カウントダウン: 3
カウントダウン: 2
カウントダウン: 1
スタート！
```

---

### 4.4 決まった回数繰り返す：for ループと range()

「5 回繰り返したい」「配列の中身をひとつずつ見たい」というときは `for` ループがぴったりです。

#### 決まった回数繰り返す（range）
```shark
// 0 から 4 まで（計 5 回）繰り返す
for var i in range(5) {
  print(f"{i} 回目のループ");
}

// 1 から 5 まで繰り返す
for var i in range(1, 6) {
  print(i);
}

// 2 ずつ増やす（0, 2, 4, 6, 8）
for var i in range(0, 10, 2) {
  print(i);
}
```

#### リストの中身を順番に取り出す
```shark
var items = ["やくそう", "どくけし", "まほうのせいすい"];

for var item in items {
  print(f"アイテム: {item}");
}
```

---

### 4.5 ループの途中で抜ける・飛ばす（break と continue）

ループの途中で「もうおしまい！」と途中で脱出したいときは `break`、今回は飛ばして「次の周に進む！」というときは `continue` を使います。

```shark
for var i in range(10) {
  if i == 3 {
    continue; // 3 のときはスキップして次へ
  }
  if i == 7 {
    break;    // 7 になったらループを完全に終了！
  }
  print(i);
}
// 画面には 0, 1, 2, 4, 5, 6 が出ます
```

## 第5章 処理をまとめる：関数と引数渡し

### 5.1 関数の作り方と呼び出し方

プログラムが長くなってくると、「ダメージを計算する」「文字をきれいに表示する」など、同じ処理を何度も書きたくなります。
そうした処理をひとまとめにして、いつでも呼び出せるようにしたものが**関数**です。

Shark では `func` というキーワードを使って関数を作ります。

```shark
// 2 つの整数を受け取って、足した結果を返す関数
func add(a: int, b: int) -> int {
  return a + b;
}

// 作った関数を呼び出す
var total = add(10, 20);
print(total); // 30
```

- `func 関数名(引数名: 型, ...) -> 戻り値の型 { ... }`
- 関数に渡すデータを**引数（ひきすう）**、関数から返ってくるデータを**戻り値（もどりち）**と呼びます。
- `return` を書くと、その瞬間に計算結果を呼び出し元に返して関数を終わります。

---

### 5.2 値を返さない関数（void）

「効果音を鳴らすだけ」「画面に文字を出すだけ」のように、計算結果を返す必要がない関数の場合は、戻り値の型に `void`（空っぽという意味）を指定するか、省略することができます。

```shark
// void を明示する書き方
func show_welcome(name: string) -> void {
  print(f"ようこそ、{name} さん！");
}

// 省略する書き方（どちらでも同じ動きになります）
func play_sound(sound_name: string) {
  print(f"♪ ピロリン（{sound_name} を再生）");
}
```

---

### 5.3 Shark の大原則：関数に渡した値はコピーされる

ここで、Shark の一番頼もしいルールをもう一度確認しましょう。
**関数に渡した引数は、すべて「コピー」されて手渡されます。**

そのため、関数の中で引数の変数を書き換えたり、リストに要素を追加したりしても、**呼び出し元のデータには指一本触れられません**。

```shark
func try_to_change(my_hp: int, items: list<string>) -> void {
  my_hp = 0;             // 関数の中で 0 にしてみる
  items.push("あくまのつるぎ"); // アイテムを追加してみる
  print("関数の中での HP:", my_hp);
}

var hero_hp = 100;
var my_bag = ["やくそう"];

// 関数を呼んでみる
try_to_change(hero_hp, my_bag);

// でも元のデータは絶対に無事！
print("手元の HP:", hero_hp);     // 100 のまま！
print("手元のアイテム:", my_bag); // ["やくそう"] のまま！
```

他の言語でよくある「関数を呼んだら知らないうちにアイテム袋の中身を消されていた」という恐ろしいバグは、Shark では絶対に起きません。いつでも安心して関数を呼ぶことができます。

---

### 5.4 元のデータを直接変えたいとき：ref キーワード

「でも、プレイヤーの HP を本当に減らす関数を作りたいときはどうするの？」と思いますよね。
そのときだけ使う特別な合言葉が **`ref`（参照）** です。

Shark では、**関数の定義側と、呼び出す側の両方に `ref` と書く**という決まりがあります。

```shark
// 定義側: 引数に ref をつける（「元のデータを貸してね」の合図）
func take_damage(ref current_hp: int, damage: int) -> void {
  current_hp -= damage;
}

var player_hp = 100;

// 呼ぶ側: ここでも必ず ref をつける！（「直接書き換えていいよ」の合図）
take_damage(ref player_hp, 30);

print(player_hp); // 70（ちゃんと書き換わっている！）
```

呼ぶ側にも `ref player_hp` と書かせることで、コードを読んだ誰が見ても「あ、この関数を呼んだら `player_hp` が書き換わるんだな」とひと目で分かります。

#### ref の安心ルール
`ref` は「関数が動いている間だけ、一時的に元の変数を借りる」仕組みです。
借りたものを自分のポケットにしまっておく（変数に代入して後で使う）ことは禁止されているので、メモリが壊れる心配もありません。

---

### 5.5 名前のない関数（無名関数 / ラムダ式）

「わざわざ名前をつけるほどでもない、ちょっとした処理」をその場に直接書くことができます。これを**無名関数**（またはラムダ式）と呼びます。

```shark
// 関数を変数に入れておく
var double = func(x: int) -> int {
  return x * 2;
};

print(double(5)); // 10
```

---

### 5.6 関数を別の関数に渡す（高階関数）

関数を変数に入れられるということは、「**関数を別の関数に引数として手渡す**」こともできるということです。

たとえば、「ゲーム画面でボタンが押されたときに動く処理」を渡すときなどに大活躍します。

```shark
// 指定された処理を 3 回実行してくれる関数
func repeat_action(count: int, action: func() -> void) -> void {
  for var i in range(count) {
    action();
  }
}

// その場で無名関数を作って手渡す！
repeat_action(3, func() -> void {
  print("敵が現れた！");
});
```

---

### 5.7 外側の変数を書き換えない安心設計

Shark の無名関数は、外側のローカル変数を直接いじることはできません。

```shark
var score = 0;
// var add_score = func() -> void { score += 10; }; // エラー！ 外側の score は見えません
```

「なんで使えないの？」と思うかもしれませんが、これも安全のためです。あちこちの無名関数が外側の変数を勝手に書き換えてしまうと、プログラムがどこで壊れたのか分からなくなってしまうからです。
値を渡したいときは引数として受け渡し、ゲーム全体で共有したい状態はトップレベル（ファイルの最初）の `var` に置きましょう。

---

## 第6章 まとまったデータを扱う（文字列・配列・マップ）

### 6.1 文字列（string）と便利な埋め込み文字列（f"{...}"）

Shark の文字列 `string` は、日本語も絵文字もとてもきれいに扱えます。
文字の長さを数えるとき、バイト数ではなく「**見た目の文字数**」で正確に数えてくれます。

```shark
var message = "こんにちは🦈";
print(message.len()); // 6（サメの絵文字もちゃんと 1 文字！）
```

#### とても便利なフォーマット文字列
文字列のクォートの前に `f` をつけると、`{ }` の中に変数や計算式をそのまま埋め込むことができます。

```shark
var name = "サメくん";
var score = 100;
print(f"勇者 {name} のスコアは {score * 2} 点です！");
```

---

### 6.2 文字列を操作する便利な機能

文字列には、よく使う便利な機能（メソッド）がそろっています。

```shark
var text = "  Hello, Shark!  ";

// 1. 前後のいらない空白を消す
print(text.trim()); // "Hello, Shark!"

// 2. 一部だけ切り取る（開始位置, 文字数）
print(text.trim().slice(0, 5)); // "Hello"

// 3. 文字を探す（何文字目にあるか。見つからないときは -1）
print(text.find("Shark")); // 9

// 4. 文字を置き換える
print(text.replace("Shark", "Friend")); // "  Hello, Friend!  "

// 5. スペースやカンマで切り分ける
var words = "りんご,みかん,ぶどう".split(",");
print(words); // ["りんご", "みかん", "ぶどう"]
```

---

### 6.3 順番に並べるリスト（list<T>）

たくさんのデータを順番に並べて入れておける箱を**リスト（可変長配列）**と呼びます。
アイテム袋や、出現した敵キャラクターのリストなどに使います。

```shark
// 初期値を入れたリスト
var items = ["やくそう", "たいまつ", "かぎ"];

// 1. 一番うしろに新しいアイテムを追加する
items.push("まほうのたね");

// 2. 一番うしろのアイテムを取り出して削除する
var last_item = items.pop(); // "まほうのたね"

// 3. 好きな場所に入れたり消したりする
items.insert(0, "ひのきのぼう"); // 先頭に挿入
items.remove_at(1);             // 1 番目のアイテムを削除

// 4. 何個入っているか数える
print(items.len()); // 3

// 5. 0 番目のアイテムを見る・書き換える
print(items[0]);   // "ひのきのぼう"
items[0] = "はがねのつるぎ";
```

もちろん、リストを別の変数に代入したときも**丸ごとコピー**されます！

```shark
var original = [1, 2, 3];
var copy = original;
copy.push(999);

print(original); // [1, 2, 3]（元のリストは絶対に変わりません）
print(copy);     // [1, 2, 3, 999]
```

---

### 6.4 キーと値で管理するマップ（map<K, V>）

「プレイヤー名と得点」や「アイテム名と所持数」のように、**名前（キー）とデータ（値）をセットで管理**したいときは**マップ（連想配列）**を使います。

> [!NOTE]
> **順番が崩れない安心仕様**:
> Shark のマップは、追加した順番をずっと覚えています。実行するたびに順番がバラバラになることはありません。

```shark
// マップを作る
var bag = {
  "やくそう": 5,
  "どくけし": 2,
  "コイン": 150,
};

// 1. 個数を見る・書き換える
print(bag["やくそう"]); // 5
bag["やくそう"] = 4;    // 使ったので 1 つ減らす
bag["かぎ"] = 1;        // 新しいアイテムを追加

// 2. 持っているか確かめる
if bag.has("コイン") {
  print("コインを持っています");
}

// 3. 捨てる（削除する）
bag.remove("どくけし");
```

---

### 6.5 リストの中のリスト（多次元データ）とコピーの動き

RPG のダンジョンマップを作るときなど、「リストの中にさらにリストを入れる（2次元配列）」こともよくあります。

```shark
var map_data = [
  [1, 1, 1],
  [1, 0, 1],
  [1, 1, 1],
];

var backup = map_data;
backup[1][1] = 9; // 真ん中を書き換えてみる

print(map_data[1][1]); // 0 のまま！（深い入れ子でも丸ごとコピーされる安心感！）
print(backup[1][1]);   // 9
```

どんなに複雑なデータ構造を作っても、「コピーしたから元データは絶対に無事」というルールは 100% 守られます。

---

## 第7章 物やキャラクターを表現する：クラス

### 7.1 クラスってなに？（設計図と実体）

ゲームを作っていると、「プレイヤー」「スライム」「ドラゴン」のように、ステータス（HP や攻撃力）と行動（攻撃する、逃げる）をセットにしたキャラクターをたくさん作りたくなります。

そのための「**キャラクターの設計図**」が**クラス**です。
設計図から生み出された実際のキャラクターのことを「インスタンス（実体）」と呼びます。

```shark
class Monster {
  var name: string;
  var hp: int;
}
```

---

### 7.2 初期化の処理（init コンストラクタ）

モンスターが生まれた瞬間に「名前」や「HP」を決めてあげる準備処理を `init` という特別な関数に書きます。自分のステータスを指すときは `this`（自分自身）を使います。

```shark
class Monster {
  var name: string;
  var hp: int;

  // 生まれたときの初期設定
  func init(name: string, hp: int) {
    this.name = name;
    this.hp = hp;
  }

  // 自分のステータスを表示する行動（メソッド）
  public func show() -> void {
    print(f"[{this.name}] HP: {this.hp}");
  }
}

// 設計図から実際のスライムを作る！
var m1 = Monster("スライム", 10);
m1.show(); // [スライム] HP: 10
```

---

### 7.3 Shark のすごいところ：クラスの実体もコピーされる！

ここが Shark の一番個性的で素晴らしいところです。
一般的なプログラミング言語（Java や C#、Python など）では、クラスの実体を変数に入れると「同じものを指す名札」になってしまい、片方を変えるともう片方も変わってしまいます。

しかし Shark では、**クラスの実体であっても、代入すると新しい実体として丸ごとコピーされます！**

```shark
var slime_a = Monster("スライムA", 10);
var slime_b = slime_a; // スライムAと全く同じスライムBが新しく誕生！

slime_b.hp = 0; // スライムBが倒された！

print(slime_a.hp); // 10（スライムAはピンピンしている！）
print(slime_b.hp); // 0
```

「キャラクターのデータをコピーして別の敵を作ったら、元の敵の HP まで連動して減ってしまった……」という初心者あるあるのバグが起きない、ゲーム開発にとてもやさしい設計です。

### 7.4 外から触れる・触れないを決める（public と private）

大切なステータスを外から勝手に書き換えられないように、鍵をかけることができます。
- `public`: 誰でも外から見て・触っていいもの
- `private`: クラスの内側からしか触れない秘密のもの（書かないと自動でこれになります）

```shark
class BankAccount {
  private var savings: int; // 外からは直接触れない

  func init(initial_money: int) {
    this.savings = initial_money;
  }

  // 正しい手順（預金）でのみ増やせる
  public func deposit(amount: int) -> void {
    if amount > 0 {
      this.savings += amount;
    }
  }

  public func get_savings() -> int {
    return this.savings;
  }
}
```

---

### 7.5 親クラスを受け継ぐ：継承と super

似たようなキャラクターを何種類も作るとき、共通の部分を「親クラス」にまとめて、それを引き継ぐ（**継承**）ことができます。親クラスの準備処理は `super.init(...)` で呼び出します。

```shark
class Animal {
  public var name: string;
  func init(name: string) {
    this.name = name;
  }
  public virtual func sound() -> string {
    return "...";
  }
}

// Animal を受け継いだ Dog クラス
class Dog : Animal {
  func init(name: string) {
    super.init(name); // 親の初期化を呼ぶ
  }
  override func sound() -> string {
    return "ワンワン！";
  }
}
```

---

### 7.6 キャラクターごとに動きを変える：virtual と override

親クラスで「子供ごとに動きを変えていいよ」と宣言するときは `virtual` をつけ、子供クラス側で「自分専用の動きに変えるよ」と上書きするときは `override` をつけます。

こうしておくと、リストに入ったいろんな動物たちに一斉に声をかけられます！

```shark
var animals: list<Animal> = [Animal("なぞの生き物"), Dog("ポチ")];

for var a in animals {
  print(f"{a.name} のなきごえ: {a.sound()}");
}
// なぞの生き物 のなきごえ: ...
// ポチ のなきごえ: ワンワン！
```

---

### 7.7 約束ごとを決める：インターフェース（interface）

「画面に描画できるもの」「音を鳴らせるもの」のように、具体的な中身は自由だけど「**この関数を必ず持っていてね**」というルール（約束）を決めるのが**インターフェース**です。

```shark
interface Drawable {
  func draw() -> void;
}

class Player : Drawable {
  override func draw() -> void {
    print("プレイヤーの絵を描く");
  }
}
```

Shark に最初から入っている `Comparable` インターフェースを実装すれば、リストの `.sort()` を呼ぶだけで好きな順番に並べ替えることができるようになります。

---

### 7.8 連続して呼び出す This 型（メソッドチェーン）

関数の戻り値に `This` と書くと、自分自身を返すことができます。これを使うと、流れるように連続して設定を書くことができます。

```shark
class CharacterBuilder {
  private var name: string;
  private var job: string;

  func init() { this.name = "名無し"; this.job = "村人"; }

  public func set_name(name: string) -> This {
    this.name = name;
    return this;
  }
  public func set_job(job: string) -> This {
    this.job = job;
    return this;
  }
}

// ドットでつなげて気持ちよく書ける！
var hero = CharacterBuilder().set_name("アーサー").set_job("騎士");
```

## 第8章 失敗と上手に付き合う：オプショナルと Result

### 8.1 なぜ「例外」がないのか？（急にいなくなるバグを防ぐ）

プログラミングをしていると、「ファイルが見つからない」「ネットワークがつながらない」といった予期せぬ失敗がどうしても起こります。

他の言語では「例外（try-catch）」がよく使われますが、例外は**どこから飛んできてどこへワープするかが非常にわかりにくく、ゲームの処理を台無しにしてしまう**ことがよくあります。

Shark では例外をすっぱりなくし、「**失敗したときは、失敗した理由を戻り値としてきちんと手渡しする**」という分かりやすい仕組みに統一されています。

---

### 8.2 「ないかもしれない」を表すオプショナル型（T? と none）

「アイテムが見つかるかもしれないし、見つからないかもしれない」という状態は、型のうしろに `?` をつけて表します。空っぽの状態は `none`（何もない）と書きます。

```shark
var found_item: string? = "金のカギ"; // 入っている
found_item = none;                   // 空っぽになった

var normal_text: string = "普通の文字";
// normal_text = none; // エラー！ 普通の箱に none は入れられません
```

「普通の箱には絶対に空っぽが入らない」と Shark が保証してくれるので、「突然中身が空っぽでゲームが止まった！」というバグを完全に予防できます。

---

### 8.3 安全に中身を取り出す（if var と ?? 演算子）

オプショナル型の箱から中身を取り出す方法は 2 つあります。

#### 1. if var（中身があったときだけ使う）
中身がちゃんとあったときだけ実行され、取り出した中身を変数に入れて使えます。

```shark
func search_chest() -> string? {
  return "宝箱のコイン"; // または return none;
}

if var item = search_chest() {
  print(f"やった！ {item} を手に入れた！");
} else {
  print("宝箱は空っぽだった……");
}
```

#### 2. ?? 演算子（空っぽなら別の値にする）
```shark
var item = search_chest() ?? "石ころ";
print(f"手に入れたもの: {item}");
```

---

### 8.4 失敗の理由も教える Result 型

ファイル読み込みのように、「失敗したときはその理由（ファイルが見つからないなど）も教えてほしい！」というときは `Result` 型を使います。

```shark
import std.file;

func load_save(filename: string) -> Result<string> {
  if !file.exists(filename) {
    return Error(f"セーブファイルがありません: {filename}");
  }
  return file.read(filename);
}

// 成功と失敗をきれいに分けて受け取る
if var text = load_save("save.dat") {
  print("ロード成功！: " + text);
} else var err {
  print("ロード失敗: " + err.message());
}
```

---

### 8.5 失敗したらすぐ引き返す try 式

いくつもの処理を連続で行うとき、いちいち `if` で確認しているとコードが階段のように深くなってしまいます。
そこで `try 式` を使うと、「**失敗したらその場で直ちに関数を抜けて、呼び出し元にエラーを返す**」ことができます。

```shark
import std.file;
import std.json;

func load_game_data(path: string) -> Result<Json> {
  // ファイルが読めなければ即座にエラーを返して抜ける
  var text = try file.read(path);

  // JSON の解析に失敗したら即座にエラーを返して抜ける
  var data = try json.parse(text);

  return data; // 両方成功したときだけここにたどり着く！
}
```

スマートで気持ちのいいエラー処理が書けますね！

---

### 8.6 どうしようもないときだけ使う panic

「絶対にありえない数字が入ってきた」「ゲームの前提条件が完全に壊れている」というバグを発見したときだけ、`panic` 関数でプログラムを安全に停止させます。

```shark
if player_count <= 0 {
  panic("プレイヤー数が 0 人です。ゲームを開始できません。");
}
```

## 第9章 同時に複数の仕事をする：タスクと並行処理

### 9.1 画面を止めずに裏で仕事をする（タスクの考え方）

ゲームを作っていると、「次のステージの大きなマップデータを読み込みたいけれど、読み込んでいる間も画面が止まらずにローディングアニメーションをクルクル回したい！」という場面が出てきます。

しかし、同時にいくつもの仕事をこなすプログラミング（マルチスレッド）は、プロのプログラマーでも頭を抱えるほど難しく、バグが出やすい分野です。

Shark では、難しい専門知識がなくても誰でも安全に同時進行ができるように、**お手伝いさん（タスク）** というやさしい仕組みを用意しています。

---

### 9.2 バックグラウンドで動かす（task）

やり方はとても簡単です。ふだん書いている関数の呼び出しの前に、魔法の言葉 `task` をつけるだけです！

```shark
func download_stage(stage_id: int) -> string {
  sleep(0.05); // 少し時間がかかる重い処理のつもり
  return f"ステージ {stage_id} のマップデータ";
}

// task をつけると、裏で勝手にお手伝いさんが動き始める！
var t = task download_stage(1);

print("画面のアニメーションを動かしながら待つよ……");
```

メインの処理は一瞬も止まらずに、次の行へと進みます。

---

### 9.3 終わるのを待って結果をもらう（wait）

「よし、そろそろ裏でのお仕事が終わったかな？」というタイミングで、`.wait()` を呼び出します。
まだ終わっていなければ終わるまで待ち、お仕事の成果（戻り値）をしっかり受け取ります。

```shark
// お仕事が終わるのを待って、データを受け取る
var stage_data = t.wait();
print("受け取ったデータ:", stage_data);
```

---

### 9.4 まとめて同時に走らせる（parallel）

「ステージデータ」と「BGM」と「敵の画像」を、3 人のお手伝いさんに同時に頼んで、ぜんぶ終わるのを一括で待ちたいときは `parallel` ブロックを使います。

```shark
func load_asset(name: string, delay: float) -> string {
  sleep(delay);
  return f"{name} の準備完了";
}

// 3 つの仕事を同時に一斉スタート！
var all_results = parallel {
  task load_asset("BGM", 0.02);
  task load_asset("マップ", 0.05);
  task load_asset("モンスター画像", 0.03);
};

// ぜんぶ終わったら、結果がリストになってまとまる！
print(all_results);
```

---

### 9.5 タスク同士でメッセージを送る（channel）

動いているお手伝いさんとおしゃべり（データのやり取り）をしたいときは、**チャネル（channel）**という「糸電話」のような道具を使います。

```shark
func worker(ch: channel<string>, id: int) -> void {
  sleep(0.02);
  _ = ch.send(f"お手伝いさん {id} 号、完了しました！");
}

var ch = channel<string>();

// 2 人のお手伝いさんをスタート
task worker(ch, 1);
task worker(ch, 2);

// メッセージが届いたら受け取る
for var i in range(2) {
  var report = ch.recv() ?? "届いていません";
  print("メインが受信:", report);
}
```

---

### 9.6 データがごちゃ混ぜにならない安心な並行処理

ここでも、Shark の「すべてはコピー」という大原則が生きています。
チャネルを通じてやり取りするメッセージも、相手に渡るときに自動的にコピーされます。
そのため、「相手がデータをいじっている最中に自分も書き換えてしまってデータが壊れる」という恐ろしい事故が 100% 起こりません。

## 第11章 画面に絵を描こう：グラフィックス入門（std.ui）

いよいよ楽しいゲーム画面作りです！

### 11.1 ゲームの画面を開いてみよう（ウィンドウの初期化）

まずはゲーム用の真っ暗なウィンドウを出してみましょう。

```shark
import std.ui;

func main() -> int {
  // 幅 640、高さ 480 のウィンドウを作る
  ui.init_window("はじめてのゲーム画面", 640, 480);

  // ウィンドウが閉じられるまでずっとループ
  while !ui.window_should_close() {
    ui.begin_frame(); // 「今から 1 コマ目を描くよ！」の合図

    // 画面全体を夜空のような紺色で塗りつぶす
    ui.clear(ui.rgb(20, 24, 40));

    // （ここに毎フレームの絵を描く）

    ui.end_frame();   // 「描き終わったよ！ 画面に出してね」の合図
  }
  return 0;
}
```

---

### 11.2 ゲームの心臓部：メインループ（begin_frame と end_frame）

ゲームは、パラパラマンガのように「毎秒 60 回」ものすごいスピードで絵を書き換えることで動いて見えます。
この繰り返しの輪を**メインループ**と呼びます。

1. `ui.begin_frame()`: 新しい紙を用意する
2. プレイヤーの位置を動かして、四角や丸を描く
3. `ui.end_frame()`: 描いた絵を画面にパッと表示して、次の瞬間まで少し待つ（60FPS を自動維持）

---

### 11.3 四角や丸、文字を描いてみよう（2D 描画）

```shark
// 赤・緑・青（0〜255）で色を作る

var yellow = ui.rgb(255, 220, 50);
var white = ui.rgb(255, 255, 255);

// 1. 塗りつぶした四角: x, y, 横幅, 高さ, 色
ui.draw_rect(50, 50, 120, 60, sky_blue);

// 2. 枠線だけの四角
ui.draw_rect_outline(50, 130, 120, 60, white, 2.0);

// 3. まんまる（円）: 中心x, 中心y, 半径, 色
ui.draw_circle(300, 100, 40, yellow);

// 4. 線を引く: スタートx, y, ゴールx, y, 色, 太さ
ui.draw_line(50, 250, 400, 250, white, 3.0);

// 5. 文字を書く: x, y, メッセージ, 文字の大きさ, 色
ui.draw_text(50, 280, "ゲームスタート！", 24, white);
```

### 11.6 3D の世界をのぞいてみよう（立体描画のしくみ）

## 第12章 かんたんアプリ作り：宣言的 UI（std.ui）

### 12.1 宣言的 UI ってなに？（view 関数を書くだけ）

先ほどのゲーム画面（第11章）は「座標 (100, 50) に四角を描く」と細かく指示するやり方でした。
でも、設定画面やツールを作るときに、ボタンや文字の位置をピクセル単位で手計算するのは大変ですよね。

そこで Shark には、「**こういうボタンと文字を並べてね**」とお願いするだけで、自動できれいにレイアウトしてくれる **宣言的 UI（Declarative UI）** が用意されています！

あなたが書くのは「画面の見た目を決める `view()` 関数」だけ。
マウスが重なったときの色変えやクリック判定は、ぜんぶ Shark が自動でやってくれます。

```shark
import std.ui;

var count = 0;

// 画面の設計図を返す関数
func view() -> Widget {
  return ui.col([
    ui.label(f"{count} 回クリックしました！"),
    ui.button("ポチッと押す", func() -> void {
      count += 1; // クリックされたら増やす
    }),
  ]);
}

func main() -> int {
  // タイトル、幅、高さ、そして view 関数を渡すだけ！
  ui.run("カウンター", 300, 200, view);
  return 0;
}
```

---

### 12.2 部品を並べる入れ物（col, row, grid, stack, center, scroll）

部品をきれいに整列させるための入れ物（コンテナ）がそろっています。

- `ui.col([...])` : 上から下へ**縦に並べる**
- `ui.row([...])` : 左から右へ**横に並べる**
- `ui.grid(列数, [...])` : カレンダーのように**格子状に並べる**
- `ui.center([...])` : まんなかに**センタリング**する
- `ui.scroll([...])` : 入り切らないときに**スクロール**できるようにする

---

### 12.3 よく使う画面の部品たち（label, button, field, slider, checkbox）

```shark
// 文字を表示する
ui.label("こんにちは！")

// 押せるボタン
ui.button("保存する", on_save)

// 文字を入力できるテキストボックス（変数を ref で渡すとリアルタイムで連動！）
ui.field(ref user_name)

// つまみを左右に動かすスライダー（音量調整など）
ui.slider(on_change, volume, 0, 100)

// チェックボックス（ON/OFF の切り替え）
ui.checkbox("BGMを鳴らす", on_change, is_sound_on)
```

---

### 12.4 色やサイズをおしゃれに変える（スタイリング）

ドットでつなげるだけで、ボタンの色や余白を自由に変えられます。

```shark
ui.button("決定", on_click)
  .padding(10, 20)                        // まわりのすき間
  .background(ui.rgb(76, 155, 232))       // ボタンの背景色
  .color(ui.rgb(255, 255, 255))           // 文字の色
  .radius(8.0);                           // 角を丸くする
```

---

### 12.5 文字を入力すると変数が直接変わる（ref バインディング）

入力欄 `ui.field(ref my_text)` に `ref` をつけて変数を渡すと、**キーボードで打った文字がその瞬間に変数 `my_text` の中に直接書き込まれます**。
「入力された文字を取り出して変数に代入し直す」という面倒なコードを 1 行も書く必要がありません。

### 12.6 実践：カウンターアプリと TODO リストを作ってみよう

最後に、実際に動く「やることリスト（TODO アプリ）」を作ってみましょう！

```shark
import std.ui;

// アプリのデータ（状態）
var todo_list: list<string> = ["宿題をやる", "Sharkでゲームを作る"];
var input_text = "";

func view() -> Widget {
  var rows: list<Widget> = [];

  // タイトル
  rows.push(ui.center([
    ui.label("🦈 マイ TODO リスト").font_size(20).color(ui.rgb(100, 180, 255))
  ]));
  rows.push(ui.divider());

  // 新しいタスクの入力欄と「追加」ボタン
  rows.push(ui.row([
    ui.field(ref input_text),
    ui.button("追加", func() -> void {
      if input_text.trim().len() > 0 {
        todo_list.push(input_text.trim());
        input_text = ""; // 入力欄を空っぽにする
      }
    }),
  ]));
  rows.push(ui.space(8));

  // リストに入っているタスクを並べる
  for var i in range(todo_list.len()) {
    var task_text = todo_list[i];
    var task_idx = i;

    rows.push(ui.row([
      ui.label(f"・ {task_text}"),
      ui.button("完了！", func() -> void {
        todo_list.remove_at(task_idx); // 終わったので削除
      }),
    ]));
  }

  return ui.padding(16, ui.col(rows));
}

func main() -> int {
  // かっこいいダークテーマにする
  ui.theme(ui.rgb(25, 28, 38), ui.rgb(240, 240, 245), ui.rgb(76, 155, 232));

  ui.run("TODO アプリ", 380, 480, view);
  return 0;
}
```

たったこれだけの短いコードで、文字入力、タスク追加、完了削除ができる本格的な GUI アプリが完成しました！

## 第13章 付録：困ったときの Q&A とよくあるエラー

### 13.1 Shark らしく書くための 5 つのコツ

1. **「代入したらコピーされる」を信じて、安心してデータを渡そう**:
   誰かにデータを渡しても壊される心配がないので、のびのびと素直な関数を作りましょう。
2. **本当に元のデータを変えたいときだけ `ref` をつけよう**:
   呼ぶときにも `ref` を書くので、「どこでデータが変わるか」が誰の目にもすぐに分かります。
3. **エラーは「例外」ではなく `?` や `Result` で受け取ろう**:
   どこにワープするか分からない例外をなくし、戻り値をきちんとチェックしましょう。
4. **タスク同士はチャネルで手紙をやり取りするように繋ごう**:
   裏で動くお手伝いさんとは、チャネルを使って安全に会話しましょう。
5. **最初は小さなプログラムから作って、動かしながら試そう**:
   `shark run` でこまめに動かしながら、少しずつ機能を追加していくのが一番の近道です。

---

### 13.2 初めての人がつまずきやすいポイントと解決法

#### Q1: 関数の中でリストに push したのに、呼び出し元のリストが増えていません！
**こたえ**: Shark では関数に渡したリストは「コピー」されるため、元のリストは守られます。元のリストを直接増やしたいときは、関数の定義と呼び出しの両方に `ref` をつけてください。
```shark
func add_item(ref bag: list<string>, new_item: string) -> void {
  bag.push(new_item);
}
add_item(ref my_bag, "やくそう");
```

#### Q2: 無名関数（ラムダ式）の中で外側の変数を書き換えようとしたらエラーになりました！
**こたえ**: 予期せぬバグを防ぐため、Shark の無名関数は外側のローカル変数を直接いじれません。変数を引数として渡すか、ファイルの先頭（トップレベル）の `var` に置きましょう。

#### Q3: 文字列と数値を `+` でくっつけようとしたらエラーになりました！
**こたえ**: 整数と文字はそのまま足せません。とても便利なフォーマット文字列 `f"{num}"` を使うか、`string(num)` で文字に変換してから足しましょう。

### 13.3 よく出るエラーコード早見表

| エラー番号 | どんな意味？ | どう直せばいい？ |
|---|---|---|
| `E0102` | 型が合っていません | 整数と小数を混ぜていないか確認し、`float(x)` などで型を合わせましょう |
| `E0110` | そんな名前の変数や関数はありません | 名前のつづり（スペル）が間違っていないか、宣言し忘れていないか確認しましょう |
| `E0120` | 条件式が true/false になっていません | `if` の条件に数値を直接置いていないか確認し、`count > 0` のように書きましょう |
| `E0156` | 外側の変数を直接いじることはできません | 無名関数の中から外のローカル変数を触ろうとしていないか確認しましょう |
| `E0180` | ref のつけ忘れ、または不要な ref です | 関数の定義と呼び出しの両方に `ref` が揃っているか確認しましょう |

### 13.4 コードをきれいに並べ直す（shark fmt）

プログラムを書いていると、字下げ（インデント）がズレて見にくくなってしまうことがあります。
そんなときは、公式フォーマッタ `shark fmt` を使えば一瞬でピカピカに整えてくれます。

```console
$ shark fmt -w game.shk
```

これでいつでも美しいコードを保つことができます！
